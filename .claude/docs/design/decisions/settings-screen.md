# 설정 화면 — 왼쪽 메뉴로 분류를 가른다

## 지금의 결정

설정 창은 **왼쪽 메뉴 + 오른쪽 패널**이다. 메뉴는 고정이고 패널만 스크롤한다. 창을 열면 맨 위 분류가 열린다.

설정은 **관심사별로 나눠** 각각을 하나의 분류에 둔다. 새 설정은 맞는 분류에 넣고, 없으면 분류를 늘린다.

**기본값으로**는 패널 밖 바닥에 둔다 — 지금 보이는 분류가 아니라 설정 전체에 걸친다.

## 왜 이렇게 정했나

설정이 늘면 관심사가 다른 값이 한 목록에 섞인다.

한 목록 안에서 작은 제목으로만 묶으면 목록이 길어지는 것을 막지 못하고, 제목이 붙은 값과 붙지 않은 값이 나란히 놓인다.

메뉴로 나누면 한 번에 한 분류만 보인다. 설정이 늘어도 창 길이는 그대로고, 나머지 분류는 메뉴에 이름으로 남는다.
