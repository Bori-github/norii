# 컬러 팔레트

## 지금의 결정

**액센트는 형광 라임 한 값이고 채운 면에만 쓴다. 상태색은 표시에만 쓴다.**

값의 단일 출처는 `apps/desktop/panda.config.ts`다. 이 문서는 토큰을 이름으로 참조한다.

### 액센트

**한다**

- 채운 면에만 쓴다 — 선택 영역 · 검색 결과 · 활성 탭 · 배지 · 강조 버튼.
- 면 위의 글자는 `text`로 둔다.
- 테마 공통 한 값으로 둔다.
- 라이트 테마에서 면에 `text` 1px 테두리를 둔다. 다크 테마에도 같은 값을 두어 버튼 정의가 갈리지 않게 한다.
- hover · pressed는 액센트를 어둡게 해서 만든다.
- 비활성은 액센트를 회수하고 무채색으로 둔다.

**하지 않는다**

- 글자색으로 쓰지 않는다(→ [액센트를 글자에서 뺀 이유](#액센트를-글자에서-뺀-이유)).
- 커서 · 포커스 링 · dirty 점 같은 가는 표시에 쓰지 않는다.
- 유리 크롬 위에 가는 표시로 올리지 않는다. 채운 면만 올린다.

### 포커스 링

**한다**

- `text`로 그리고 종이 위에서만 쓴다.
- 유리 위(사이드바 트리)는 링 대신 배경으로 표시한다.

WebKit이 방향키 이동의 프로그램적 `focus()`에 `:focus-visible`를 걸어주지 않아 링은 키보드 탐색 중 사라진다.

### 상태색

**한다**

- 정보 · 성공 · 경고 · 위험을 둔다. 콜아웃 상자를 종류별로 나누고, 충돌과 삭제를 표시한다.
- 테마 공통 단일 값으로 두고 표시(비텍스트)에만 쓴다.
- 충돌·삭제된 탭은 제목과 아이콘을 위험색으로 칠한다. 유리 위에서도 그대로 쓴다 — 삼각형 아이콘과 배너가 색을 대신할 신호로 함께 뜬다.

**하지 않는다**

- 글자색으로 쓰지 않는다. 액센트를 글자에서 뺀 것과 같은 계산이다.

### 종이

**한다**

- 라이트 종이는 R·G·B 세 값을 2 이내로 붙인다.
- 무채색 스케일은 따뜻한 쪽으로 기울인다.

**하지 않는다**

- 유리 틴트에 색을 넣지 않는다(→ [유리](glass.md)).

마크다운 문서의 스크린샷은 배경이 거의 항상 순백(`#FFFFFF`)이라, 라이트 종이에 색이 있으면 그 이미지의 네 변이 눈에 띈다. 다크 종이는 밝기 차이가 커서 경계가 어차피 드러나므로 색을 가져도 된다.

### 구문 마크

**한다**

- 글자색 토큰이므로 테마별 두 값을 쓰고, AA(4.5:1)를 넘긴다.

**하지 않는다**

- 크롬에 흐린 글자를 쓰지 않는다. 비활성 탭 제목도 본문색으로 쓴다.

## 왜 이렇게 정했나

색을 고른 뒤 검사하지 않고, **대비 게이트를 먼저 돌려 통과하는 색만 후보에 올린다**(→ [대비 게이트](../design-system.md#대비-게이트)). 크롬이 유리라 뒤가 통제 불가능하기 때문이다.

### 액센트를 글자에서 뺀 이유

```text
글자로 쓸 때 (AA 4.5:1)
  흰 종이 위에서 통과하려면      휘도 ≤ 0.183
  어두운 종이 위에서 통과하려면  휘도 ≥ 0.201
  → 두 조건이 모순. 색 계열과 무관하게 어떤 색도 존재하지 않는다.
```

이 계산에는 색상이 들어가지 않는다. 팔레트를 무엇으로 바꿔도 결론이 같으므로, **이 규칙은 팔레트가 바뀔 때 다시 검토할 대상이 아니다.**

## 트레이드오프

- **링크·강조 텍스트·커서·dirty 점·포커스 링이 전부 `text`다.** 색이 아니라 밑줄·굵기·형태로만 구별된다.
- **라이트 테마에서는 액센트 면에 테두리가 항상 따라붙는다.** 채움만으로 경계가 서지 않는다.
- **밝은 바탕화면에서 충돌 표시가 흐려진다.** 비활성 탭은 유리라 위험색 대비가 기준 아래로 떨어진다. 색이 아닌 신호(아이콘 · 배너)가 남는 것을 근거로 받아들였다.
- **경고·성공이 3:1 기준선에 붙어 있다.** 라이트 종이를 어둡게 바꾸면 이 둘이 먼저 막힌다.
